## Reddit r/SideProject (English)

**Title:** I shipped v2.6.0 of my local-first resume builder — optional CV photos, full-workspace backup, and safer autosave

**Body:**

I built an open-source Markdown/form resume editor that runs in the browser without requiring an account. This release adds:

- Optional, locally cropped 3:4 photos for China-market CV layouts (hidden by default for many international applications).
- Versioned JSON export/import for multiple profiles, saved drafts and job-description notes.
- Recovery for layout/market settings if the user reloads while IndexedDB autosave is still pending.

There is A4 / US Letter preview, ATS-oriented guidance and two PDF paths: selectable-text browser print, or a direct raster download.

Privacy caveat: the full-workspace JSON file is **unencrypted** and may contain resumes and saved photos. Keep it private; the app does not automatically sync across devices.

## 私信 / 评论 FAQ

**照片上传到服务器吗？** 不需要，证件照在本地处理并跟随当前浏览器的档案保存；完整 JSON 备份包含照片，应妥善保管。

**换设备会同步吗？** 不会。须先从旧浏览器导出完整工作区，再到新浏览器主动导入；不要删除旧数据直到核对成功。

**PDF 文字能复制吗？** 使用浏览器的 ATS 矢量 PDF 打印保存可选择文字；快速 PDF 是光栅直接下载。最终请检查排版和分页。

**免费使用吗？** 无需注册即可使用当前在线编辑器。不要承诺未来永久免费或保证求职结果。
