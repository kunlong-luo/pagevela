# 已有帖子的评论 / 私信更新用语

## 为什么换名字？
**中文：**「Resume Craft / 简匠」现在统一叫 **Pagevela**，是同一开源简历工具，官网和 GitHub 仓库地址已更新；历史发布记录与下载包保留旧名。
**English:** Resume Craft is now **Pagevela**. It is the same open-source resume builder with a new public name and website; historical releases stay as published.

## 旧链接为什么打不开？
**中文：**旧的 `https://kunlong-luo.github.io/resume-craft/` 页面已停用且不跳转，请改用 https://kunlong-luo.github.io/pagevela/。如果原链接含分享参数，请不要公开贴出带个人信息的完整 URL。
**English:** The retired /resume-craft/ Pages URL is not redirected. Current site: https://kunlong-luo.github.io/pagevela/. Please avoid posting personal resume share URLs publicly.

## 简历会上传吗？
**中文：**日常编辑的主要简历数据保存在本地浏览器；完整工作区 JSON 导出文件**未经加密**，请妥善保管。不同设备或浏览器不会自动同步。
**English:** The main resume-editing data is stored locally in your browser. Workspace JSON exports are not encrypted; store them privately. There is no automatic cross-device sync.

## ATS 会保证通过吗？
**中文：**不会。Pagevela 有 ATS 导向的排版/关键字检查，但不能保证任何招聘系统的判断。
**English:** No. ATS-oriented guidance is useful, but no tool can guarantee how an employer's applicant tracking system will evaluate a resume.

## v2.6.0 为什么还是 Resume Craft？
**中文：**这是 2026-10-14 以旧品牌发布的历史版本；为了保存文件兼容性与校验记录，不修改历史压缩包。以后新版本的 GitHub Release 标题使用 Pagevela。
**English:** v2.6.0 was released under the original brand. Its archives and checksums were intentionally preserved. Future GitHub Release titles use Pagevela.

## 有新版截图吗？
**中文：**网站 OG 封面已是 Pagevela。真实编辑器截图应由当前网站采集并经人工检查；旧图片不带旧品牌且内容准确时不必重做。
