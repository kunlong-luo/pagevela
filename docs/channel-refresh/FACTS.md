- 历史文件名：`resume-craft-*` 的压缩包、截图工作流 artifact 名以及加密/IndexedDB 标识可能保留用于兼容，不等于现在的对外品牌。
- 文章：引用过去“我当时开发 Resume Craft”是历史事实，应在前面加“现名 Pagevela”；不要随意更改历史发布日期、链接永久地址或既往评价。
- 真实截图：尽量由 GitHub Actions 现有 `Capture Real Promotion Media` 从当前 `main` 生成，只使用虚构示例简历。未经人工检查的图片不要上传平台。
