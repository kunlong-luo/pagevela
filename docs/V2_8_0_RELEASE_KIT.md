## English — launch post draft

**Title:** Pagevela v2.8.0 — better mobile resume editing, safer releases

Pagevela is a local-first Markdown resume editor with a structured form, A4 / US Letter preview, ATS-oriented checks and PDF export, without account registration.

Version 2.8.0 improves the mobile Form / Code / Preview workflow, keeps the preview's final lines clear of bottom actions, brings a scan-friendly QR button next to Start on the faster welcome page, and unifies bilingual menus. It also gates GitHub Pages updates on a successful full Chromium, Firefox and WebKit browser suite.

Try it: https://kunlong-luo.github.io/pagevela/  
Latest Release: https://github.com/kunlong-luo/pagevela/releases/tag/v2.8.0

ATS guidance is not a guarantee of hiring-system compatibility. Resumes are stored locally and exported workspace backups are unencrypted.

## 中文 — 发布公告草稿

**标题：** Pagevela（页帆）v2.8.0：移动端简历编辑更顺手，发布流程更可靠

Pagevela 是本地优先的 Markdown 简历编辑器，支持结构化表单、A4 / US Letter 实时预览、ATS 辅助检查与 PDF 导出，无需注册。

v2.8.0 统一移动端「表单／源码／预览」切换，优化底部工具按钮避免遮挡简历最后几行；欢迎页更快显示，Start 左侧可打开二维码弹窗，方便手机扫码使用。中英文控件与菜单风格也更一致。完整 Chromium、Firefox、WebKit 测试通过后，网站才会自动部署更新。

在线体验：https://kunlong-luo.github.io/pagevela/  
最新版：https://github.com/kunlong-luo/pagevela/releases/tag/v2.8.0

ATS 检查仅供参考；简历数据主要保存在浏览器本地，工作区备份 JSON 未加密，需谨慎存放。
